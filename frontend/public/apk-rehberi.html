ParçaTakip PRO · APK Dönüştürme Rehberi

React (CRA) → Android APK · Capacitor
Bu rehber ne yapar? Mevcut web uygulamanızı (React frontend) Capacitor ile sarmalayıp Android telefonlarda kurulabilen bir .apk dosyasına dönüştürmenizi adım adım anlatır. Backend (FastAPI) ve veritabanı (MongoDB) telefonun içinde değil, bir sunucuda çalışmaya devam eder; APK sadece o sunucuya bağlanan arayüzdür.

İçindekiler

1. Nasıl çalışır? (Mimari) 2. Ön koşullar (kurulacak programlar) 3. Backend adresini ayarla (ÇOK ÖNEMLİ) 4. Capacitor kurulumu ve yapılandırma 5. Web'i derle ve Android'e aktar 6. 1. Nasıl çalışır? (Mimari)

APK, uygulamanızın görsel arayüzünü (React build çıktısı) telefonun içine gömer. Veriler ise internetteki backend'inizden gelir:

[ Android Telefon: APK ]
        │  (HTTPS istekleri)
        ▼
[ Sunucu: FastAPI backend ]  ←→  [ MongoDB veritabanı ]
        │
        ▼
[ Dosya depolama (teknik resimler) ]
Kritik: APK içindeki React kodu localhost'a bağlanamaz. Backend'inizin internetten erişilebilir bir adreste (örn. https://api.sirketiniz.com veya fabrika ağındaki sabit bir IP) yayında olması gerekir.

3. Backend adresini ayarla (ÇOK ÖNEMLİ)

APK derlemeden önce frontend'in hangi backend'e bağlanacağını sabitleyin. frontend/.env dosyasını açıp REACT_APP_BACKEND_URL'i canlı sunucunuza çevirin:

# frontend/.env
REACT_APP_BACKEND_URL=https://api.sirketiniz.com
Fabrika içi (yerel ağ) kullanım için sunucunuzun sabit IP'sini yazabilirsiniz, örn. http://192.168.1.50:8001. Ancak Android 9+ varsayılan olarak şifresiz (http) trafiği engeller — bkz. Bölüm 9 (cleartext ayarı).

4. Capacitor kurulumu ve yapılandırma

frontend klasörünün içinde şu komutları çalıştırın:

cd frontend

# Capacitor çekirdek + Android platformu + CLI
yarn add @capacitor/core @capacitor/android
yarn add -D @capacitor/cli

# Capacitor'ı başlat (soruları aşağıdaki gibi yanıtlayın)
npx cap init "ParcaTakip PRO" "com.sirketiniz.parcatakip" --web-dir=build

capacitor.config.json

npx cap init aşağıdaki dosyayı oluşturur. Kendiniz de frontend/capacitor.config.json olarak oluşturabilirsiniz:

{
  "appId": "com.sirketiniz.parcatakip",
  "appName": "ParcaTakip PRO",
  "webDir": "build",
  "server": {
    "androidScheme": "https",
    "cleartext": true
  },
  "android": {
    "allowMixedContent": true
  }
}
appId benzersiz olmalı (ters domain formatı). Google Play'e yükleyecekseniz gerçek domain'inizi kullanın. cleartext:true yalnızca http (şifresiz) backend kullanıyorsanız gereklidir; https kullanıyorsanız false yapıp daha güvenli olur.

5. Web'i derle ve Android'e aktar

cd frontend

# 1) React üretim derlemesi (build/ klasörünü üretir)
yarn build

# 2) Android platform klasörünü ekle (ilk seferde bir kez)
npx cap add android

# 3) build çıktısını Android projesine kopyala (her değişiklikte)
npx cap sync android
İpucu: Frontend'de her değişiklik yaptığınızda tekrar yarn build && npx cap sync android çalıştırmanız yeterli.

6. APK üretme

A) Android Studio ile (kolay yol)

1
Projeyi açın: npx cap open android
2
Android Studio açılınca üst menüden Build → Build Bundle(s) / APK(s) → Build APK(s).
3
Derleme bitince çıkan bildirimde "locate" ile APK'yı bulun. Konum: android/app/build/outputs/apk/debug/app-debug.apk
4
Bu app-debug.apk dosyasını telefona atıp kurabilirsiniz (test için yeterli).

B) Komut satırı ile

cd frontend/android

# Debug APK (imzasız, test için)
./gradlew assembleDebug
# Çıktı: app/build/outputs/apk/debug/app-debug.apk

# Release APK (Play Store / dağıtım için imzalı)
./gradlew assembleRelease

Release APK'yı imzalama (dağıtım için)

Telefonlara resmî olarak dağıtmak veya Play Store'a yüklemek için imza anahtarı gerekir:

# 1) Anahtar (keystore) oluştur
keytool -genkey -v -keystore parcatakip.keystore \
  -alias parcatakip -keyalg RSA -keysize 2048 -validity 10000

Sonra android/app/build.gradle içine imza yapılandırmasını ekleyin:

android {
    signingConfigs {
        release {
            storeFile file("../../parcatakip.keystore")
            storePassword "PAROLANIZ"
            keyAlias "parcatakip"
            keyPassword "PAROLANIZ"
        }
    }
    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled false
        }
    }
}

7. Google Girişi (mobilde dikkat)

Uygulama şu an Emergent'in yönettiği Google Auth'u kullanıyor ve giriş, tarayıcı üzerinden yönlendirme (redirect) ile çalışıyor. WebView içinde Google, güvenlik nedeniyle bazı OAuth ekranlarını engelleyebilir.

Önerilen çözümler:

  • Capacitor Browser eklentisi ile girişi sistem tarayıcısında açmak: yarn add @capacitor/browser ve giriş linkini Browser.open() ile açın; dönüşte derin bağlantı (deep link) ile uygulamaya geri dönün.
  • Ya da bağımsız barındırmaya geçerken kendi Google Cloud OAuth anahtarınızı kullanıp mobil için resmi @capacitor-community/google-auth / native Google Sign-In eklentisine geçmek (en sağlıklısı).

İsterseniz bu geçişi (mobil uyumlu native Google Sign-In) sizin için biz yapabiliriz.

9. Sık karşılaşılan sorunlar

Beyaz ekran açılıyor: REACT_APP_BACKEND_URL yanlış ya da erişilemez. Doğru canlı adresi yazıp tekrar yarn build && npx cap sync android yapın.

"Cleartext HTTP traffic not permitted": http (şifresiz) backend kullanıyorsanız capacitor.config.json içinde "cleartext": true olmalı. Alternatif olarak android/app/src/main/AndroidManifest.xml içindeki <application> etiketine android:usesCleartextTraffic="true" ekleyin. En iyisi backend'i https yapmaktır.

API istekleri CORS hatası: Backend'de CORS_ORIGINS mobil şemayı da kabul etmeli. Capacitor Android şeması https://localhost veya capacitor://localhost olabilir; backend'de CORS'u * ya da bu değerleri içerecek şekilde ayarlayın.

Gradle hatası: Android Studio → File → Sync Project with Gradle Files; JDK 17 seçili olmalı.

Özet komut dizisi (kopyala-yapıştır): 
cd frontend
yarn add @capacitor/core @capacitor/android
yarn add -D @capacitor/cli
npx cap init "ParcaTakip PRO" "com.sirketiniz.parcatakip" --web-dir=build
yarn build
npx cap add android
npx cap sync android
npx cap open android   # Android Studio'da: Build → Build APK(s)
